Clarion — Privacy Policy

Last updated: 2026-07-19

Clarion collects no data. None. There is nothing to send, because Clarion makes no network requests.

What Clarion does

Clarion is a Chrome extension that reformats JSON, YAML and XML responses you open in a browser tab into a readable, collapsible tree. All parsing and rendering happens locally, inside your browser. The content you view never leaves your machine.

Data we collect

None. Specifically, Clarion does not:

  • send any HTTP request, WebSocket, or beacon to any server (ours or a third party's);
  • include any analytics, telemetry, crash reporting, or "phone home" logic;
  • read, store, or transmit your browsing history;
  • use cookies or tracking identifiers.

This is independently verifiable: open Chrome DevTools → Network on any page where Clarion is active, and on the extension's service worker. You will see zero outbound requests originating from Clarion. The source code is open and auditable, and an automated check:network test in the build forbids any network primitive in the codebase.

Data stored locally

Clarion uses chrome.storage.local to remember your preferences only (for example your theme choice). This data stays on your device and is never transmitted. You can clear it at any time from the extension's options page or by removing the extension.

Permissions

  • storage — to save your preferences (e.g. theme) locally.
  • Host access (<all_urls>) — required so Clarion can reformat a JSON/YAML/XML response on any API URL you choose to open. Clarion only reads the content already loaded in the tab to render it; it makes no request of its own. It never modifies network traffic.

Payments (future Pro features)

The current version is entirely free and contains no payment code. If and when optional Pro features are introduced, payment will be handled by a dedicated third-party processor on a separate payment page; that processor's own privacy policy will apply to the transaction. The "zero tracking, zero network" promise of the viewer itself will not change.
